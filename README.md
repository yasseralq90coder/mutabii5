# مُتابِعي — نسخة APK

نفس تطبيق الويب **بالحرف** (مطابق 100%)، مُغلَّف كتطبيق أندرويد، مع إضافات أصلية:

## ١) تنبيهات تعمل والتطبيق مغلق
- **الأذان** بمواقيت التطبيق نفسها (مكة/الحرم كأساس)، لكل صلاة على حدة + تنبيه قرب الوقت + الإقامة، مع زر إيقاف الأذان.
- **منبّه استيقاظ قوي**: شاشة كاملة فوق القفل، صوت متصاعد يُفرَض على الأقصى، اهتزاز، ولا يتوقف إلا بمسألة حسابية أو عدد نقرات — كله قابل للتعديل.
- تُفتح الإعدادات من الزر العائم **⏰**.

## ٢) مشغّل القرآن في شريط الإشعارات
- يستمر التشغيل بعد الخروج من التطبيق.
- شريط تحكّم مثل تطبيقات الموسيقى: **اسم السورة + اسم القارئ**، مع تشغيل/إيقاف، السورة السابقة/التالية، وشريط التقدّم — يظهر أيضاً على **شاشة القفل**.
- يستجيب لأزرار سماعات البلوتوث والسيارة.

## ٣) أندرويد أوتو
يظهر التطبيق في أندرويد أوتو مع تصفّح **١١٤ سورة** وتشغيلها والتحكم بها من شاشة السيارة.

> ملاحظة مهمة: أندرويد أوتو يمنع التطبيقات المثبّتة يدوياً (خارج المتجر) افتراضياً.
> لتفعيله: افتح تطبيق **Android Auto** → مرّر لأسفل → اضغط على **الإصدار/Version** عشر مرات لتفعيل وضع المطوّر → من القائمة (⋮) اختر **إعدادات المطوّر** → فعّل **مصادر غير معروفة (Unknown sources)**.

## ٤) إصلاحات مهمة
- **زر استعادة JSON يعمل الآن** (وكذلك استيراد CSV واختيار ملفات الصوت). السبب السابق: WebView لا يفتح منتقي الملفات إلا بتفعيل `onShowFileChooser` — وقد فُعِّل.

---

## البناء والتحميل (من الجوال)
1. أنشئ مستودعاً جديداً على github.com.
2. **Add file → Upload files** → ارفع **كل الملفات** → **Commit**.
   - تأكد من رفع مجلد `.github`. إن لم يظهر: **Add file → Create new file** بالاسم `.github/workflows/build.yml` والصق محتواه.
3. تبويب **Actions** → البناء يبدأ تلقائياً (٣–٥ دقائق).
4. تبويب **Releases** → حمّل **Mutabii.apk** وثبّته.

## بعد التثبيت
افتح التطبيق مرة، اضغط **⏰** ثم:
- فعّل **① المنبّهات الدقيقة** و **② تجاهل تقييد البطارية** (ضروريان).
- اختر ملف أذان الحرم من **صوت الأذان → اختيار ملف**.
- اضبط منبّه الاستيقاظ ثم **💾 حفظ وتفعيل**.
